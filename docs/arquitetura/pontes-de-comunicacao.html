Pontes de Comunicação

Como as três conexões (POS, Visa, HSM) atravessam o Redis entre os dois processos — pswitch-comunicacao (segura os sockets de verdade) e pswitch-app (processa, sem nenhum socket). A única coisa que cruza essa linha é fila do Redis — nenhuma chamada de método Java atravessa processo.

pswitch-comunicacao (sockets) pswitch-app (switch, zero sockets) fronteira Redis
  • Validado de ponta a ponta com os dois processos rodando separados de verdade — uma transação POS real passou por HSM (SE e G0) e Visa, aprovada, sem nenhuma chamada de método Java cruzando de um processo pro outro.
  • pswitch-app não carrega vestígio nenhum de pswitch-comunicacao — confirmado via mvn dependency:tree. O HsmRequestManager mora em pswitch-external (só precisa de Redis, nunca de socket).
  • Ainda não implementado: múltiplas réplicas do switch nem múltiplos grupos co-localizados — hoje é um grupo só, com uma réplica só, de cada lado.
